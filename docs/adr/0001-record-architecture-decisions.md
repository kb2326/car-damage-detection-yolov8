# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-01

## Context

Design choices in this project (tools, models, agent boundaries) need to be explainable later to
reviewers, to future contributors, and to auditors in a regulated domain.

## Decision

Record each significant decision as an Architecture Decision Record (Michael Nygard's format) in
`docs/adr/NNNN-title.md`, with Status, Context, Decision, and Consequences. ADRs are never edited
after acceptance; a new ADR supersedes an old one.

## Consequences

Decisions become reviewable and searchable. Writing one takes about 15 minutes per decision.
